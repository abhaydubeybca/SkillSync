# SkillSync — Sequenced Website Prototype

## Page sequence
1. `index.html` — Home / landing page
2. `account.html` — Create student account
3. `login.html` — Log in
4. `explore-projects.html` — Explore live projects
5. `find-teammates.html` — Find matching teammates
6. `create-project.html` — Create a project
7. `team-dashboard.html` — Team dashboard
8. `smart-campus.html` — Smart Campus project dashboard
9. `profile.html` — Student profile
10. `how-it-works.html` — How SkillSync works

## Run it
Extract the ZIP and open `index.html` in a browser. All pages share `style.css` and `app.js`. Use the navigation links to move between pages.

## Important
This is a frontend prototype. Forms show demo feedback; there is no real authentication, database, server-side validation, or saved account data. Some metrics and match scores in the source pages are sample/demo content.
